## Project purpose
A proposed Oracle PL/SQL application for managing pharmacy products, suppliers, purchases, batches, sales, stock levels and expiry monitoring.

## Data source
[Kaggle Pharma Sales Data](https://www.kaggle.com/datasets/milanzdravkovic/pharma-sales-data). Verify the licence, fields and record count before using it. Sales data alone may not contain batch or expiry information.

## Planned innovation
An interactive Oracle APEX dashboard connected to Oracle Database.

## Project phases
Phase 0: Research and proposal  
Phase I: Business process modeling  
Phase II: Data sourcing and normalization  
Phase III: Oracle PDB creation  
Phase IV: Database tables and data loading  
Phase V: PL/SQL programming  
Phase VI: Triggers, business rules and auditing  
Phase VII: Documentation, innovation and final presentation
